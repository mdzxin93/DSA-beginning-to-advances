# 148. Print a Pattern with Concentric Squares

**Difficulty**: Medium  
**Topics**: Pattern Printing  

---

### Description
Print a pattern with concentric squares using stars. The outer square should be larger and each subsequent square should be centered inside.

### Example
- Input: `n = 5`
- Output:
```
*****
*   *
*   *
*   *
*****
```
