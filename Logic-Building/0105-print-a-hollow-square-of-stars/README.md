# 105. Print a Hollow Square of Stars

**Difficulty**: Easy  
**Topics**: Pattern Printing  

---

### Description
Print a hollow square pattern with stars (`*`). The border of the square should be filled with stars while the inner part should be empty.

### Example
- Input: `n = 5`
- Output:
```
*****
*   *
*   *
*   *
*****
```
