# 101. Print a Right-Angle Triangle of Stars

**Difficulty**: Easy  
**Topics**: Pattern Printing  

---

### Description
Print a right-angle triangle pattern of stars (`*`). Each row should contain an increasing number of stars, starting from 1 star in the first row.

### Example
- Input: `n = 4`
- Output:
```
*
**
***
****
```
